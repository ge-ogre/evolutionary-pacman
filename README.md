# Evolutionary Pac-Man

Genetic algorithm to run simulation of Pac-Man. Player agents are trained using Tensorflow Keras. Built for CIS 400/600 Evolutionary Machine Learning

## How to run

**Set up the environment:**
   ```bash
   conda env create -f environment.yml
   conda activate pacman
   ```

**Launch the main GUI by running:**
```bash
python3 main.py
```
